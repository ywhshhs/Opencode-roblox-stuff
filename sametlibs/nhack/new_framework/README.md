# Nova UI Framework

A clean, modern Roblox Luau UI library built from studying the NHack library patterns.
Designed for clarity, good separation of concerns, and maintainable code.

## Structure

- **Core.lua** — Main library object, services, helpers
- **Elements.lua** — UI widgets (Window, Page, Section, Toggle, Slider, Dropdown, Button, Colorpicker, Keybind)
- **Example.lua** — Usage example
